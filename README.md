# 콩콩마을 🫘

콩이랑 놀다 보면 생각이 쑥쑥 자라는 아이 교육게임 마을이에요. 휴대폰, 태블릿, PC 브라우저에서 바로 할 수 있어요.

- 주소: https://ustick7.github.io/kongkong-town/
- 문제는 놀이를 시작할 때마다 새로 만들어져요.
- 6~8세(7세 중심) 기준이에요. 단계마다 6세·7세·초1 표시가 붙어 있어요.

## 문제 푸는 방식
- 아이는 스티커를 자유롭게 놓고 바꾸고 뺄 수 있어요. **✔ 다 했어요**를 눌러야 채점돼요. 그래서 끌다가 잘못 놓은 건 틀린 것으로 세지 않아요.
- 💡 힌트는 문제마다 2번까지. 답이 아니라 **생각하는 방법**만 알려 줘요.
- 결과는 다섯 가지로 기록돼요: 혼자 맞힘 / 힌트 보고 맞힘 / 틀린 뒤 고쳐 맞힘 / 힌트+고쳐 맞힘 / 못 풀고 나감. 처음 보는 놀이의 '같이 해 보기'는 연습으로 따로 기록해요.
- 영콩·위콩은 맞힌 뒤 낱말이나 이름을 **소리 내어 따라 말해야** 다음으로 넘어가요. 마이크로 확인하고, 마이크를 못 쓰는 기기는 아이가 말했다고 누르거나 부모님이 확인해요.
- 같은 답이 두 문제 연달아 나오지 않아요.
- 손글씨 받아쓰기는 부모님 설정에 무료 Gemini 키를 붙여 넣으면 콩이(AI)가 글씨를 읽고 글자마다 채점해요. 같은 사진을 두 가지 방법으로 읽어 둘이 똑같을 때만 채점해요. 키가 없거나 잘 못 읽으면 아이가 정답과 비교하고 '확인 기다림'으로 남아요. 이때는 콩알·별을 주지 않고, 부모님이 그 자리(비밀번호)나 리포트에서 ⭕를 눌러야 받아요. 쓴 글씨는 사진으로 리포트에 남고 부모님이 ⭕/❌로 확정할 수 있어요. 만드는 법: [worker/README.md](worker/README.md)

## 부모님 기능
- 처음 켜면 부모님 설정: 아이 이름, 시작 미션, 하루 놀이 시간, 비밀번호 4자리
- 문제를 맞히면 콩알을 받아요 (확인된 정답만). 🪴 콩이 정원에서 콩알로
  - 물을 줘 화분을 키우고, 콩꼬투리가 열리면 수확해서 콩 도감(8가지)을 채워요
  - 콩이 꾸미기(머리·얼굴·목·손·등·몸 색 6부위), 화분 바꾸기, 정원 친구 16마리, 배경 6가지를 사요. 일부는 수확 횟수로 열려요
  - 🎠 놀이터: 옆으로 넓은 마당에서 콩이와 친구들이 걸어 다니며 그네·미끄럼틀·시소 등을 타요. 놀이기구·장식(18가지)을 사서 아무 데나 놓고 끌어서 옮겨요
  - 오늘의 공부: 하루에 문제 10개를 맞히면 보너스 콩알 5개
- 📊 학습 리포트: 과목별 탭, 결과 다섯 가지 비율, 과목 맞춤 코칭, 부족한 부분과 '이 부분 연습하기', 기술별 실력, 손글씨 사진, 다시 볼 문제(비슷한 문제 다시 풀기, 고치면 ✓ 표시), 카톡으로 보내기
- 기록은 그 기기 브라우저에 저장돼요 (서버 없음)

## 구조 (새 과목·놀이 추가하기)
```
index.html              스크립트 불러오기
core/engine.js          공통 엔진: 콩이, 소리, 읽어 주기, 끌어다 놓기, 답 칸, 힌트, 채점, 화면 전환
core/kit.js             여러 과목이 함께 쓰는 문제 틀(quiz, sort, write 손글씨)과 한글 자모 도구
core/home.js            시작 미션, 비밀번호, 놀이 시간
core/garden.js          콩이 정원 (화분·수확·도감·꾸미기·오늘의 공부)
core/park.js            콩이 놀이터 (넓은 마당, 놀이기구 놓기·옮기기, 걸어 다니는 콩이와 친구들)
core/houses.js          마을의 과목별 집 그림
core/vendor/            html2canvas (리포트를 그림으로 공유, MIT)
core/report.js          풀이 기록과 과목별 맞춤 리포트
core/core.css           공통 디자인 (폰·태블릿·PC)
subjects/index.js       마을의 집(과목) 목록
subjects/<과목>/*.js     과목별 놀이 (*2.js는 추가 놀이)
core/ocr.js             손글씨 읽기 (Gemini 키로 바로, 또는 채점 서버로)
worker/ocr-worker.js    (선택) 손글씨 채점 서버 (Cloudflare Workers + Gemini, 무료)
core/ages.js            단계별 나이 표시 (단계에 age가 없을 때)
```
- 새 놀이: `K.area('<과목id>', {skills, levels, types, tip})`로 등록하고 `index.html`에 스크립트 한 줄을 추가해요.
- 문제마다 `skill`을 붙이면 리포트에서 그 기술의 실력이 따로 계산돼요. 이름은 놀이의 `skills`에 적어요.
