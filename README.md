# 콩콩마을 🫘

콩이랑 놀다 보면 생각이 쑥쑥 자라는 아이 교육게임 마을이에요. 휴대폰 브라우저에서 바로 할 수 있어요.

- 주소: https://ustick7.github.io/kongkong-town/
- 첫 과목: **생각콩**(창의사고력). 셈콩·영콩·말콩·받콩·돈콩은 곧 열려요.

## 생각콩 놀이
| 놀이 | 내용 |
|---|---|
| 규칙 찾기 | 반복 기차, 늘었다 줄었다, 빙글빙글 무당벌레 |
| 무게 비교 | 시소 놀이터, 무거운 쪽, 바꿔치기, 평평하게, 두 번 바꾸기, 무게 순서 |
| 가르기·모으기 | 바구니에 모으기, 보자기 속 가르기, 모든 방법 찾기 |
| 거울 대칭 | 접었다 펴기로 반대쪽 칠하기 |
| 쌓기나무 | 층별로 세기, 숨은 나무 찾기, 비교하기 |
| 자리 추리 | 단서를 보고 자리 찾기 (✓/✗ 바로 확인) |

모든 문제는 **보여 주기 → 만져 보기 → 말로 하기 → 확인하기** 순서로 설명하고, 틀리면 힌트를 한 단계씩 더 줘요.

## 부모님 기능
- 처음 켜면 부모님 설정: 아이 이름, 시작 미션(양치했어요 등), 하루 놀이 시간, 비밀번호 4자리
- 아이가 미션을 "했어요"로 누르면 부모님 비밀번호를 넣어야 시작돼요
- 문제를 풀면 콩알을 받고, 콩알로 콩이 화분에 물을 주면 씨앗부터 콩꼬투리까지 자라요
- 기록은 그 폰 브라우저에 저장돼요 (서버 없음)

## 구조 (새 과목·놀이 추가하기)
```
index.html              스크립트 불러오기
core/engine.js          공통 엔진: 콩이, 소리, 읽어 주기, 끌어다 놓기, 힌트, 별점, 화면 전환
core/home.js            시작 미션, 비밀번호, 놀이 시간, 콩이 화분
core/core.css           공통 디자인
subjects/index.js       마을의 집(과목) 목록
subjects/think/*.js     생각콩 놀이 하나당 파일 하나
```
- 새 과목: `subjects/index.js`에 `K.subject({...})` 한 줄을 넣고 `soon`을 빼요
- 새 놀이: `subjects/<과목>/<놀이>.js`에서 `K.area('<과목id>', {levels, types, tip})`로 등록하고 `index.html`에 스크립트 한 줄을 추가해요
