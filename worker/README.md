# ✍️ 손글씨 자동 채점 만들기 (무료, 15분)

받아쓰기에서 아이가 쓴 글씨를 콩이가 직접 읽고 글자마다 채점하게 하는 방법이에요.
**카드 등록 없이 무료**로 만들 수 있어요. 한 번만 해 두면 돼요.

만드는 것은 두 가지예요.
1. **Gemini 키**: 구글 AI가 글씨를 읽어 줘요.
2. **Cloudflare Worker**: 게임과 구글 AI 사이에서 키를 안전하게 지켜 주는 작은 서버예요. 키를 게임 안에 넣으면 누구나 볼 수 있어서 이렇게 따로 둬요.

PC에서 하면 편해요.

---

## 1단계. Gemini 키 받기 (3분)

1. https://aistudio.google.com/apikey 에 들어가서 구글 계정으로 로그인해요.
2. 약관 동의 창이 나오면 동의해요.
3. **API 키 만들기 (Create API key)** 를 눌러요. 프로젝트를 고르라고 하면 아무거나 또는 새로 만들기를 눌러요.
4. 나온 키 (`AIza…`로 시작) 를 **복사**해서 메모장에 잠깐 붙여 둬요.

> 결제 정보를 넣지 않으면 무료 등급으로만 쓰여서 돈이 나가지 않아요.

## 2단계. Cloudflare Worker 만들기 (7분)

1. https://dash.cloudflare.com/sign-up 에서 이메일로 무료 가입하고, 받은 메일에서 인증해요.
2. 왼쪽 메뉴에서 **Compute (Workers) → Workers & Pages** 를 눌러요.
3. **Create (만들기)** → **Hello World 로 시작 (Start with Hello World)** 를 골라요.
4. 이름을 `kongkong-ocr` 로 바꾸고 **Deploy (배포)** 를 눌러요.
5. **Edit code (코드 편집)** 를 눌러요.
6. 왼쪽 `worker.js` 안의 글자를 **모두 지우고**, 아래 주소의 내용을 **전부 복사해서 붙여 넣어요.**
   https://raw.githubusercontent.com/ustick7/kongkong-town/main/worker/ocr-worker.js
7. 오른쪽 위 **Deploy (배포)** 를 눌러요.

## 3단계. 키 넣기 (2분)

1. Worker 화면에서 **Settings (설정) → Variables and Secrets (변수 및 비밀)** 로 가요.
2. **Add (추가)** 를 눌러요.
   - Type: **Secret (비밀)**
   - Name: `GEMINI_KEY`
   - Value: 1단계에서 복사한 키
3. **Deploy (배포)** 또는 **Save (저장)** 를 눌러요.

## 4단계. 게임에 연결 (1분)

1. Worker 화면 위쪽에 있는 주소 `https://kongkong-ocr.○○○.workers.dev` 를 복사해요.
2. 콩콩마을 → ⚙️ 부모님 설정 → **✍️ 손글씨 자동 채점** 칸에 붙여 넣어요.
3. **연결 확인**을 눌러서 ✅ 가 나오면 끝이에요. 아래 **저장**도 눌러 주세요.

아이 폰이 여러 대면 폰마다 4단계만 해 주면 돼요.

---

## 이렇게 동작해요
- 아이가 **다 썼어요**를 누르면 글씨 사진만 보내요. 이름이나 다른 기록은 보내지 않아요. **정답도 보내지 않아서** AI가 틀린 글씨를 맞게 고쳐 읽지 않아요.
- 콩이가 읽은 글자와 정답을 글자마다 비교해서 ⭕/❌를 보여 줘요. 틀리면 다시 쓰게 해요.
- 글씨를 잘 못 읽었거나, 인터넷이 안 되거나, 무료 사용량을 넘으면 예전처럼 **아이가 스스로 비교**해요.
- AI가 맞게 쓴 글씨를 틀렸다고 할 때를 위해 **👪 부모님: 맞게 썼어요** 버튼이 있어요 (비밀번호 필요).
- 📊 리포트에서 사진마다 콩이가 읽은 글자를 보고, ⭕ 맞아요 / ❌ 틀렸어요로 고칠 수 있어요.

## 알아 두면 좋은 것
- **무료 사용량**: Cloudflare는 하루 10만 번, Gemini 무료 등급은 하루 수백 번 정도라서 한 가정이 쓰기에 충분해요. 넘으면 그날은 스스로 비교로 바뀌어요.
- **개인정보**: Gemini 무료 등급은 구글이 서비스 개선에 입력을 쓸 수 있어요. 보내는 건 글씨 사진뿐이라 이름이나 얼굴은 들어가지 않아요.
- 연결이 안 되면 Worker의 **Logs (로그)** 를 보거나, `GEMINI_KEY` 이름에 오타가 없는지 확인해 주세요.
- 다른 모델을 쓰고 싶으면 변수 `MODEL` 을 추가해요 (기본값 `gemini-2.5-flash`).
