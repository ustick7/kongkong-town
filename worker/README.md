# ✍️ 손글씨 자동 채점 켜기 (무료, 5분)

받아쓰기에서 아이가 쓴 글씨를 콩이가 직접 읽고 글자마다 채점하게 하는 방법이에요.
**카드 등록 없이 무료**예요. 할 일은 **키 하나 받아서 붙여 넣기**뿐이에요.

## 1. Gemini 키 받기 (3분, PC나 폰 모두 돼요)

1. https://aistudio.google.com/apikey 에 들어가서 구글 계정으로 로그인해요.
2. 약관 동의 창이 나오면 동의해요.
3. **API 키 만들기 (Create API key)** 를 눌러요. 프로젝트를 고르라고 하면 아무거나 또는 새로 만들기를 눌러요.
4. 나온 키 (`AIza…`로 시작) 를 **복사**해요.

> **결제(Billing)는 켜지 마세요.** 결제 정보를 넣지 않으면 무료 등급으로만 쓰여서 돈이 나갈 수 없어요. 한도를 넘으면 그날만 막히고 끝이에요.

## 2. 게임에 붙여 넣기 (1분)

1. 아이 폰에서 콩콩마을 → ⚙️ **부모님 설정** → **✍️ 손글씨 자동 채점** 칸에 키를 붙여 넣어요.
2. **연결 확인**을 눌러 ✅ 가 나오면 끝이에요. (아래 **저장**을 눌러도 저장돼요.)

아이 폰이 여러 대면 폰마다 2단계만 해 주면 돼요. 키는 그 폰에만 저장되고, '기록 내보내기' 파일에도 들어가지 않아요.

### (선택) 키를 더 안전하게
키가 혹시 새어 나가도 다른 곳에서 못 쓰게 묶어 둘 수 있어요.
1. https://console.cloud.google.com/apis/credentials 에서 방금 만든 키를 눌러요.
2. **애플리케이션 제한사항 → 웹사이트** 를 고르고 `https://ustick7.github.io/*` 를 넣어요.
3. **API 제한사항 → 키 제한 → Generative Language API** 만 체크하고 저장해요.

### (고급, 안 해도 돼요) 채점 서버로 키 숨기기
키를 폰에 두지 않고 Cloudflare Worker에 두고 싶으면 이 폴더의 `ocr-worker.js` 를 Worker로 배포하고 비밀 변수 `GEMINI_KEY` 에 키를 넣은 뒤, 게임 설정 칸에 키 대신 Worker 주소(`https://….workers.dev`)를 넣으면 돼요. 동작은 똑같아요.

## 이렇게 동작해요
- 아이가 **다 썼어요**를 누르면 글씨 사진만 구글에 보내요. 이름이나 다른 기록은 보내지 않아요. **정답도 보내지 않아서** AI가 틀린 글씨를 맞게 고쳐 읽지 않아요.
- **확실할 때만 채점해요.** 같은 사진을 두 번, 두 가지 방법(글자 그대로 / 자음·모음으로 나눠서)으로 읽게 해요. 두 결과가 똑같고 둘 다 '확실하다'고 할 때만 채점하고, 하나라도 다르거나 헷갈리면 부모님 확인으로 넘겨요. 그래서 AI가 대충 맞는 낱말로 짐작해 읽어도 맞았다고 하지 않아요.
- 콩이가 읽은 글자와 정답을 글자마다 비교해서 ⭕/❌를 보여 줘요. 틀리면 다시 쓰게 해요.
- 글씨를 잘 못 읽었거나, 인터넷이 안 되거나, 무료 사용량을 넘으면 아이가 정답과 비교해요. 이때는 **콩알을 주지 않고** '확인 기다림'으로 남아요. 부모님이 그 자리에서 확인하거나 리포트에서 ⭕를 눌러야 콩알이 나와요.
- AI가 맞게 쓴 글씨를 틀렸다고 할 때를 위해 **👪 부모님: 맞게 썼어요** 버튼이 있어요 (비밀번호 필요).
- 📊 리포트에서 사진마다 콩이가 읽은 글자를 보고, ⭕ 맞아요 / ❌ 틀렸어요로 고칠 수 있어요.

## 알아 두면 좋은 것 (2026년 11월 21일 공식 문서로 확인)

**안 쓰면 멈추거나 지워지나요?**
- **Cloudflare Workers 무료**: 공식 한도 문서에 '안 쓰면 멈춤·삭제' 규칙은 없어요. 지워지는 건 30일 넘은 **예전 버전 기록**뿐이고, 지금 배포된 Worker는 그대로 살아 있어요. (Vercel·Supabase 무료 DB처럼 1주일 안 쓰면 잠드는 방식이 아니에요.)
- **Gemini 키**: 공식 문서에 키가 기간이 지나 만료된다는 말은 없어요. 다만 구글이 모델을 바꾸면 예전 모델은 언젠가 끝나요. 그래서 콩콩마을은 **무료 Flash 모델 여러 개를 차례로 시도**해요 (3.5 Flash → 3.1 Flash-Lite → 2.5 Flash). 그래도 모두 안 되면 게임은 아이 스스로 비교로 바뀌니까 놀이가 멈추지는 않아요.
- 가끔 ⚙️ 설정에서 **연결 확인**을 눌러 보면 살아 있는지 바로 알 수 있어요.

**무료 사용량**
- Cloudflare(고급 방법을 쓸 때만): 하루 **10만 번** (한국 시간 오전 9시에 초기화). 한 가정은 하루 수십 번이라 넉넉해요.
- Gemini: 무료 한도는 모델마다 다르고 구글이 바꾸기도 해서 문서에 숫자가 없어요. https://aistudio.google.com/rate-limit 에서 지금 한도를 볼 수 있어요. 넘으면 그날은 스스로 비교로 바뀌어요 (매일 오후 4~5시쯤 초기화).
- 한국은 Gemini API 사용 가능 국가 목록에 들어 있어요.

**개인정보**
- Gemini 무료 등급은 **보낸 내용을 구글이 서비스 개선에 쓸 수 있다**고 가격표에 적혀 있어요. 보내는 건 칸에 쓴 글씨 사진뿐이고, 이름·얼굴·기록은 보내지 않아요.

**문제가 생기면**
- '키가 맞지 않아요'가 나오면 AIza부터 끝까지 빠짐없이 다시 복사해 주세요. 앞뒤 빈칸은 괜찮아요.
- '오늘 무료 사용량을 다 썼어요'가 나오면 다음 날 다시 돼요. 그동안은 아이가 스스로 비교하고 부모님이 확인해요.
- 고급 방법(Worker)에서 'GEMINI_KEY가 없어요'가 나오면 비밀 변수 이름에 오타가 없는지 봐 주세요. Worker 화면의 **Logs** 에서 오류를 볼 수 있어요.
