# ✍️ 손글씨 자동 채점 만들기 (무료, 15분)

받아쓰기에서 아이가 쓴 글씨를 콩이가 직접 읽고 글자마다 채점하게 하는 방법이에요.
**카드 등록 없이 무료**로 만들 수 있어요. 한 번만 해 두면 돼요.

만드는 것은 두 가지예요.
1. **Gemini 키**: 구글 AI가 글씨를 읽어 줘요.
2. **Cloudflare Worker**: 게임과 구글 AI 사이에서 키를 안전하게 지켜 주는 작은 서버예요. 키를 게임 안에 넣으면 누구나 볼 수 있어서 이렇게 따로 둬요.

PC에서 하면 편해요.

---

## 1단계. Gemini 키 받기 (3분)

1. https://aistudio.google.com/apikey 에 들어가서 구글 계정으로 로그인해요.
2. 약관 동의 창이 나오면 동의해요.
3. **API 키 만들기 (Create API key)** 를 눌러요. 프로젝트를 고르라고 하면 아무거나 또는 새로 만들기를 눌러요.
4. 나온 키 (`AIza…`로 시작) 를 **복사**해서 메모장에 잠깐 붙여 둬요.

> **결제(Billing)는 절대 켜지 마세요.** 결제 정보를 넣지 않으면 무료 등급으로만 쓰여서 돈이 나갈 수 없어요. 한도를 넘으면 그날만 막히고 끝이에요.

**(권장) 키를 Gemini 전용으로 묶기** – 키가 새어 나가도 다른 데 못 쓰게 해요.
1. 키 목록에서 방금 만든 키의 프로젝트 이름을 눌러 Google Cloud 콘솔로 가요. (또는 https://console.cloud.google.com/apis/credentials)
2. 키를 눌러 **API 제한사항 → 키 제한 → Generative Language API** 만 체크하고 저장해요.
   (AI Studio에서 만든 키는 이미 이렇게 묶여 있는 경우가 많아요. 그러면 그대로 두면 돼요.)

## 2단계. Cloudflare Worker 만들기 (7분)

1. https://dash.cloudflare.com/sign-up 에서 이메일로 무료 가입하고, 받은 메일에서 인증해요.
2. 왼쪽 메뉴에서 **Compute (Workers) → Workers & Pages** 를 눌러요.
3. **Create (만들기)** → **Hello World 로 시작 (Start with Hello World)** 를 골라요.
4. 이름을 `kongkong-ocr` 로 바꾸고 **Deploy (배포)** 를 눌러요.
5. **Edit code (코드 편집)** 를 눌러요.
6. 왼쪽 `worker.js` 안의 글자를 **모두 지우고**, 아래 주소의 내용을 **전부 복사해서 붙여 넣어요.**
   https://raw.githubusercontent.com/ustick7/kongkong-town/main/worker/ocr-worker.js
7. 오른쪽 위 **Deploy (배포)** 를 눌러요.

## 3단계. 키 넣기 (2분)

1. Worker 화면에서 **Settings (설정) → Variables and Secrets (변수 및 비밀)** 로 가요.
2. **Add (추가)** 를 눌러요.
   - Type: **Secret (비밀)**
   - Name: `GEMINI_KEY`
   - Value: 1단계에서 복사한 키
3. **Deploy (배포)** 또는 **Save (저장)** 를 눌러요.

### (선택) 하루 횟수 정확히 세기
Worker에는 **하루 300번** 제한이 들어 있어요. 주소가 혹시 새어 나가도 무료 사용량을 다 써 버리지 않게요. 아무것도 안 해도 동작하지만, 아래를 해 두면 더 정확하게 세요.
1. 왼쪽 메뉴 **Storage & Databases → Workers KV → Create** 에서 이름 `kongkong-count` 로 만들어요.
2. Worker의 **Settings → Bindings → Add → KV namespace** 에서 이름(Variable name) `COUNT`, 방금 만든 `kongkong-count` 를 골라 저장해요.
3. 횟수를 바꾸고 싶으면 변수 `DAILY_MAX` (예: `500`) 를 추가해요.

## 4단계. 게임에 연결 (1분)

1. Worker 화면 위쪽에 있는 주소 `https://kongkong-ocr.○○○.workers.dev` 를 복사해요.
2. 콩콩마을 → ⚙️ 부모님 설정 → **✍️ 손글씨 자동 채점** 칸에 붙여 넣어요.
3. **연결 확인**을 눌러서 ✅ 가 나오면 끝이에요. 아래 **저장**도 눌러 주세요.

아이 폰이 여러 대면 폰마다 4단계만 해 주면 돼요.

---

## 이렇게 동작해요
- 아이가 **다 썼어요**를 누르면 글씨 사진만 보내요. 이름이나 다른 기록은 보내지 않아요. **정답도 보내지 않아서** AI가 틀린 글씨를 맞게 고쳐 읽지 않아요.
- 콩이가 읽은 글자와 정답을 글자마다 비교해서 ⭕/❌를 보여 줘요. 틀리면 다시 쓰게 해요.
- 글씨를 잘 못 읽었거나, 인터넷이 안 되거나, 무료 사용량을 넘으면 예전처럼 **아이가 스스로 비교**해요.
- AI가 맞게 쓴 글씨를 틀렸다고 할 때를 위해 **👪 부모님: 맞게 썼어요** 버튼이 있어요 (비밀번호 필요).
- 📊 리포트에서 사진마다 콩이가 읽은 글자를 보고, ⭕ 맞아요 / ❌ 틀렸어요로 고칠 수 있어요.

## 알아 두면 좋은 것 (2026년 11월 21일 공식 문서로 확인)

**안 쓰면 멈추거나 지워지나요?**
- **Cloudflare Workers 무료**: 공식 한도 문서에 '안 쓰면 멈춤·삭제' 규칙은 없어요. 지워지는 건 30일 넘은 **예전 버전 기록**뿐이고, 지금 배포된 Worker는 그대로 살아 있어요. (Vercel·Supabase 무료 DB처럼 1주일 안 쓰면 잠드는 방식이 아니에요.)
- **Gemini 키**: 공식 문서에 키가 기간이 지나 만료된다는 말은 없어요. 다만 구글이 모델을 바꾸면 예전 모델은 언젠가 끝나요. 그래서 Worker는 **무료 Flash 모델 여러 개를 차례로 시도**해요 (3.5 Flash → 3.1 Flash-Lite → 2.5 Flash). 그래도 모두 안 되면 게임은 아이 스스로 비교로 바뀌니까 놀이가 멈추지는 않아요.
- 가끔 ⚙️ 설정에서 **연결 확인**을 눌러 보면 살아 있는지 바로 알 수 있어요.

**무료 사용량**
- Cloudflare: 하루 **10만 번** (한국 시간 오전 9시에 초기화). 한 가정은 하루 수십 번이라 넉넉해요.
- Gemini: 무료 한도는 모델마다 다르고 구글이 바꾸기도 해서 문서에 숫자가 없어요. https://aistudio.google.com/rate-limit 에서 지금 한도를 볼 수 있어요. 넘으면 그날은 스스로 비교로 바뀌어요 (매일 오후 4~5시쯤 초기화).
- 한국은 Gemini API 사용 가능 국가 목록에 들어 있어요.

**개인정보**
- Gemini 무료 등급은 **보낸 내용을 구글이 서비스 개선에 쓸 수 있다**고 가격표에 적혀 있어요. 보내는 건 칸에 쓴 글씨 사진뿐이고, 이름·얼굴·기록은 보내지 않아요.

**문제가 생기면**
- 연결 확인에서 'GEMINI_KEY가 없어요'가 나오면 3단계 이름에 오타가 없는지 봐 주세요.
- Worker 화면의 **Logs** 에서 오류를 볼 수 있어요.
- 특정 모델을 쓰고 싶으면 변수 `MODEL` 을 추가해요 (예: `gemini-3.5-flash`).
